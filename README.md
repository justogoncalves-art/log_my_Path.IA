# MY PATH.IA

Plataforma de módulos psicopedagógicos para colegios, profesionales privados y particulares.

- `prototipo/`: maqueta HTML original (login, home y pantallas de Mento.IA / My Campus.IA).
- `.claude/skills/`: skills de desarrollo del proyecto.

La plataforma nueva (Next.js + Supabase) se arma en la raíz de este repositorio.
